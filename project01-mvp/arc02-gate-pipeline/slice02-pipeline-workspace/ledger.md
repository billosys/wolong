## What Worked

- Splitting workspace ownership into `wolong-workspace` kept cleanup safety
  testable without running the full pipeline.
- Explicit `run-*-to` gate helpers avoided broad runner changes while giving
  the pipeline stable artifact paths.
- Fixture invocation markers made short-circuit tests falsifiable: absence of
  `grounder.invoked` or `engine.invoked` proves the later gate did not run.
