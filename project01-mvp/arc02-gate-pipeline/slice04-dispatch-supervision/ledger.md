## What Worked

- Wrapping the existing `wolong-pipeline:run/2` kept gate classification,
  erlexec timeout cleanup, workspace ownership, and public plan adaptation
  separate from OTP dispatch lifecycle.
- `temporary` one-shot workers made crash semantics explicit: the failed request
  returns a typed dispatch error and is not replayed, while the permanent
  dispatch supervisor remains available for later requests.
- Per-test unique base directories plus slow-success/engine-timeout fixture
  markers made concurrency and no-zombie assertions deterministic in Common
  Test.
