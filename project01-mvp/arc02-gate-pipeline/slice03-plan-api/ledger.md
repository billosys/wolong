## What Worked

- Capturing the engine artifact payload in `wolong-pipeline` before cleanup
  let the public adapter stay narrow while satisfying `keep-artifacts=false`.
- Keeping `wolong:plan/3` as a translation layer over `wolong-pipeline:run/2`
  made scope review straightforward: no duplicate argv/status/workspace code.
- Public CT cases over fixture marker files made short-circuit behavior
  observable at the API boundary rather than inferred from internals.
