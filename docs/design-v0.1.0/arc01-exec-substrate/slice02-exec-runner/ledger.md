## What Worked

- Direct erlexec `monitor` mode gave the runner the right contract surface:
  separate stdout/stderr messages plus a `DOWN` message for typed completion.
- The missing-command test exposed a useful erlexec edge: without preflight,
  a missing command name can look like a completed process with stderr. The
  owned runner now normalizes that boundary before later gates depend on it.
- The `ltest` avoidance from slice01 held: concrete tag/value assertions under
  `rebar3 as test eunit` were enough and preserved a meaningful nonzero exit
  on tamper.
